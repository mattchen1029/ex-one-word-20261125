An entry for the [make.fun bounty "Describe Your Ex in One Word"](https://make.fun/bounty/u-puan-describe-your-ex-in-one-word-9fc6ebe7?ref=r2d6z7t8).

## The word

> Uninstalled

Eleven characters, one word — the ex summed up as an app you removed from your phone: one tap, no ceremony, and it never reappears on the home screen. Instantly a verdict, and anyone who has ever deleted an ex's number feels the truth in it.

## How it works

`main.py` writes that single word (exactly one word, 1–111 characters, plain text) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). It validates the gate first: one word, 1–111 characters, not only whitespace.

Run it grader-style:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 -P -s main.py
```
